## 1. UX «для бабушки» — максимум 3 экрана
1) **Загрузка**: одна огромная кнопка «Выбрать фото» (2–5 фото на первом этапе, позже до 20), превью миниатюрами, кнопка «Сделать фильм». Опционально одно поле «О чём фильм?» с подсказкой («Внуки на огороде») — можно не заполнять.
2) **Обработка**: дружелюбный прогресс человеческими словами («Рассматриваем фото…», «Оживляем внуков…», «Склеиваем фильм…», «Подбираем музыку…»), примерное время, можно закрыть приложение — пришлём уведомление/СМС.
3) **Результат**: большой плеер, кнопки «Скачать», «Отправить в WhatsApp/Telegram», «Сделать ещё».
Требования доступности: русский язык, шрифт от 20px, кнопки от 64px высотой, высокий контраст, никаких терминов (нет слов «модель», «рендер», «промпт», «API», «агент»), работа с телефона одной рукой, понятные ошибки («Фото слишком тёмное — попробуйте другое»).

## 2. Скрыть всю инфраструктуру
Никаких ключей API, выбора моделей, списков агентов, очередей, настроек качества в интерфейсе. Всё это — только серверный конфиг (env/секреты, models.yaml, роутер рецептов выбирает пайплайн автоматически). Пользователь видит только фото → кнопку → фильм. Опиши, где лежит конфиг, как ротируются ключи, как сервер сам выбирает рецепт и fallback-модель.

## 3. Конвейер (сервер), предложи стадии и контракты между ними
ingest фото (EXIF-поворот, дедуп, оценка качества) → детекция людей/лиц/объектов + удаление/чистка фона → раскадровка из фото (LLM+vision: сюжет, порядок, 1 сцена на фото, план движения камеры и персонажей) → короткие клипы image-to-video по 5–10 с (Kling/Seedance/Wan-класс; первый/последний кадр, цепочка last-frame) → QC каждого клипа (дрейф лица, «заморозка», рваное движение, анатомия; авто-перегенерация до N раз, иначе заменить на мягкий Ken Burns по фото) → склейка в 2–3 мин (стыки, переходы, ритм под музыку) → лёгкая цветокоррекция + музыка/шумы + титры → экспорт MP4 (1080p, H.264, AAC) и отправка.
**Будь честен про ограничения**: однокнопочное «кино» за один проход сегодня нереально; 2–3 минуты = 15–30 коротких клипов, каждая склейка — риск; физика и руки у i2v-моделей ещё ошибаются; честная стратегия — поэтапное качество, QC-фильтры и безопасные fallback-сцены. Дай оценку себестоимости и времени на 30 с и на 2–3 мин.

## 4. Первый этап (MVP)
Ролик 15–30 секунд из 2–5 фото, одна кнопка, без настроек. Критерий готовности: 8 из 10 тестовых наборов фото дают ролик без заморозок и кривой анимации. Потом — наращивание длины (60 с → 2–3 мин), сюжетные шаблоны («Огород», «День рождения», «Внуки», «Дача»), озвучка.

## 5. Open Design (open-design.ai, GitHub nexu-io/open-design) — как опору для оболочки
Open Design — это open-source рабочее пространство ИИ-дизайн-агента (аналог Claude Design): прототипы UI, дашборды, слайды, HyperFrames (HTML→MP4 моушн-графика), короткие клипы 3–15 с. Это НЕ продукт «фото → 2–3 мин семейное кино». Используй его идеи только для: дизайн-системы и согласованности UI, live-preview при разработке оболочки, опционально — анимированные титры/заставки (HTML→MP4). Конечный пользователь НЕ ставит ни Claude, ни Open Design.
