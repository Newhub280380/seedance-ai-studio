# Open Design (open-design.ai, github.com/nexu-io/open-design)

Что это: open-source рабочее пространство ИИ-дизайн-агента (аналог Claude Design): прототипы UI, дашборды, слайды, HyperFrames (HTML→MP4 моушн-графика), короткие клипы Seedance/Kling ~3–15 с.

## Берём
1. Как инструмент сборки простой оболочки (загрузка → прогресс → результат) и live-preview при разработке.
2. Дизайн-систему: единые цвета/шрифты/кнопки, крупные элементы для пожилых.
3. Опционально: заставки, титры, финальные надписи («Наш огород, лето 2026») через HTML→MP4.

## Не берём / не обещаем
- Не основа для фильма 2–3 мин из семейных фото — это делает наш серверный конвейер (`/workspace/studio`).
- Конечный пользователь не ставит ни Open Design, ни Claude; никаких их панелей в продукте.
- Короткие клипы из Open Design — не замена нашей цепочке клипов с QC.
