# Честно: что реально, что нет (ноябрь 2026)

## Реально
- Ролик 15–30 с из 2–5 фото по одной кнопке: оживление каждого фото клипом 5–10 с, склейка, музыка, титры.
- Удаление/замена фона, улучшение фото, аккуратные движения камеры и лёгкая анимация людей.
- Автоматическая проверка качества и перегенерация брака; при неудаче — мягкий «наезд камеры» по фото вместо кривой анимации.
- Полностью скрытая инфраструктура: ключи и модели только на сервере.

## С оговорками
- 2–3 минуты = 15–30 клипов; каждый стык — риск. Делаем поэтапно (30 с → 60 с → 2–3 мин).
- Лица «плывут» между клипами, руки/инструменты/физика (лопата, вода, земля) иногда ломаются — лечится QC и перегенерацией, но не на 100%.
- Время: минуты–десятки минут на фильм; стоимость — доллары за фильм (зависит от моделей), не копейки.

## Нереально сейчас
- «Кино за один проход» одной моделью на 2–3 минуты без ошибок.
- Сложный сюжет с диалогами и точной физикой без ручной доводки.
- Open Design сам по себе такой продукт не делает (он для дизайна интерфейсов и коротких моушн-роликов).
